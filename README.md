# KasiSkill

**Connecting communities with skilled local service providers.**

## About the Project

KasiSkill is a digital platform designed to connect customers with local skilled workers, particularly in plumbing and general maintenance.

The platform aims to improve access to employment opportunities while helping communities find reliable service providers.

## Main Objectives

- Connect customers with local skilled workers.
- Help workers access more job opportunities.
- Support local economic development.
- Build trust through worker assessment and verification.

## Main Service Categories

- Plumbing
- General Maintenance

## Technology Stack

**Frontend:** React, TypeScript and Vite

**Backend:** Python and FastAPI

**Database:** PostgreSQL

**Deployment:** Northflank
